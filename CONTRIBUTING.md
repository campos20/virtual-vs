## Developer Certificate of Origin (DCO)

We use the [Developer Certificate of Origin](https://developercertificate.org/)
instead of a separate contributor license agreement, so the copyright history
of the project stays clean and attributable to its actual authors.

Every commit must be signed off, confirming you wrote it (or otherwise have
the right to submit it under the project's license):

```bash
git commit -s -m "Your commit message"
```

This appends a `Signed-off-by: Your Name <you@example.com>` trailer to the
commit message, using the name and email from your git config. Pull requests
with unsigned commits will be asked to amend before merge.
